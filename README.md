# Python Basics 🐍

A beginner-friendly Python repository containing basic concepts, examples, and practice programs. This repository is designed to help students learn Python from fundamentals to intermediate-level programming through hands-on examples.

* Variables and Data Types
* Input and Output
* Operators
* Conditional Statements (`if`, `elif`, `else`)
* Loops (`for`, `while`)
* Functions
* Strings
* Lists
* Tuples
* Sets
* Dictionaries
* File Handling
* Exception Handling
* Object-Oriented Programming (OOP)
* Modules and Packages
* Basic Projects and Practice Programs

## 🚀 Getting Started

### Prerequisites

* Python 3.x installed
* VS Code (Recommended)

Check Python installation:

```bash
python --version
```

### Clone the Repository

```bash
git clone https://github.com/aj3041111-oss/python-basic.git
```

Navigate to the project directory:

```bash
cd python-basic
```

Run any Python file:

```bash
python filename.py
```
